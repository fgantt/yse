================================================================================
SUMMARY: WHY NNUE FAILED
================================================================================

The NNUE implementation failed due to 7 interconnected failures:

1. Arbitrary scaling (no activation)      → Search breaks
2. Broken TD(λ) training                  → No learning
3. Bootstrap loop (self-play with NNUE)   → Learning garbage
4. Suboptimal architecture                → Limited capacity
5. Weight initialization 4000x too large  → Saturation
6. Not integrated into search             → No impact
7. No strength tests                      → Unknown if working

These combined to make NNUE useless:
- Training converged (low TD error) but to wrong solution
- Evaluations meaningless for search heuristics
- Never actually improved move quality
- No one measured to check if it worked
